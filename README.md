# House Expenses

تطبيق iPhone لإدارة مدفوعات بناء المنزل باستخدام **Swift + UIKit** و**Core Data**. يستهدف iOS 26 أو أحدث، وتُبنى الواجهات برمجيًا دون Storyboard.

## الوظائف المعتمدة

يسجل التطبيق المبلغ بالريال السعودي، وصف الدفعة، التصنيف، والملاحظات. يُنشأ التاريخ تلقائيًا وقت الإضافة. تدعم النسخة الأولى الإضافة والتعديل والحذف، مع إدارة التصنيفات بالإضافة والتعديل والحذف، والبحث في الوصف والملاحظات واسم التصنيف، والفرز حسب التاريخ أو المبلغ أو التصنيف، وإظهار عدد العمليات ومجموع النتائج الحالية.

يمكن إرفاق صور الفواتير والمستندات من الكاميرا أو مكتبة الصور، إضافة إلى ملفات PDF من تطبيق الملفات. تُحفظ المرفقات محليًا داخل Application Support، بينما تُحفظ بياناتها الوصفية في Core Data.

## التشغيل

بعد عمل Clone للمستودع، افتح الملف `HouseExpenses.xcodeproj` مباشرة في Xcode. المشروع مُعد مسبقًا باستخدام Swift وUIKit، ويربط ملفات Swift و`Info.plist`، ويستهدف iOS 26. لا تحتاج إلى إنشاء مشروع Xcode جديد أو إضافة الملفات يدويًا. اختر Simulator أو جهاز iPhone من شريط Xcode ثم اضغط زر التشغيل.

إذا طلب Xcode اختيار Team للتوقيع، اختر حساب Apple الخاص بك من إعدادات Signing & Capabilities. قبل تشغيل وظائف المرفقات، تأكد من وجود مفاتيح `NSCameraUsageDescription` و`NSPhotoLibraryUsageDescription` الموجودة في `Info.plist`.

## ملاحظات مهمة

يحتوي المستودع على مشروع Xcode كامل، وطبقة التخزين، ونموذج الحالة، ومدير المرفقات، وشاشات المدفوعات والتصنيفات والإضافة والتعديل. بعد فتح `HouseExpenses.xcodeproj`، ابدأ باختبار إنشاء تصنيف، ثم إضافة دفعة، ثم البحث والفرز، ثم تعديل وحذف الدفعة، وأخيرًا إرفاق صورة وملف PDF. لا يمكن تشغيل Simulator أو بناء تطبيق iOS فعليًا داخل بيئة Linux؛ يلزم Xcode على macOS للتحقق النهائي والتوقيع والتثبيت على iPhone.
