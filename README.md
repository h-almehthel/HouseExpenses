# House Expenses

تطبيق iPhone لإدارة مدفوعات بناء المنزل باستخدام **Swift + UIKit** و**Core Data**. يستهدف iOS 26 أو أحدث، وتُبنى الواجهات برمجيًا دون Storyboard.

## الوظائف المعتمدة

يسجل التطبيق المبلغ بالريال السعودي، وصف الدفعة، التصنيف، والملاحظات. يُنشأ التاريخ تلقائيًا وقت الإضافة. تدعم النسخة الأولى الإضافة والتعديل والحذف، مع إدارة التصنيفات بالإضافة والتعديل والحذف، والبحث في الوصف والملاحظات واسم التصنيف، والفرز حسب التاريخ أو المبلغ أو التصنيف، وإظهار عدد العمليات ومجموع النتائج الحالية.

يمكن إرفاق صور الفواتير والمستندات من الكاميرا أو مكتبة الصور، إضافة إلى ملفات PDF من تطبيق الملفات. تُحفظ المرفقات محليًا داخل Application Support، بينما تُحفظ بياناتها الوصفية في Core Data.

## التشغيل

افتح Xcode على جهاز Mac وأنشئ مشروع iOS App جديدًا باسم `HouseExpenses`، واختر Swift وUIKit. أضف جميع ملفات مجلد `HouseExpenses` إلى Target التطبيق، واستبدل `AppDelegate.swift` و`SceneDelegate.swift` بالنسخ الموجودة هنا. اجعل Minimum Deployment هو iOS 26، وأوقف استخدام Storyboard من إعدادات المشروع، وأضف محتوى `Info.plist` أو مفاتيح الخصوصية الموجودة في الملف المرفق. تأكد من إضافة `NSCameraUsageDescription` و`NSPhotoLibraryUsageDescription` قبل تشغيل وظائف المرفقات.

## ملاحظات مهمة

يحتوي المستودع على طبقة التخزين، ونموذج الحالة، ومدير المرفقات، وشاشات المدفوعات والتصنيفات والإضافة والتعديل. بعد إنشاء مشروع Xcode وإضافة الملفات، ابدأ باختبار إنشاء تصنيف، ثم إضافة دفعة، ثم البحث والفرز، ثم تعديل وحذف الدفعة، وأخيرًا إرفاق صورة وملف PDF. لا يمكن تشغيل Simulator أو بناء تطبيق iOS فعليًا داخل بيئة Linux؛ يلزم Xcode على macOS للتحقق النهائي والتوقيع والتثبيت على iPhone.
